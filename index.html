zinbot

A personal-use assistant powered by Hermes, operated for its owner's own accounts and everyday work.

What the assistant does

With the owner's explicit Google authorization, the assistant can retrieve and summarize email, find and read selected Drive files, read Google Docs and Sheets, and help manage calendar events.

The personal Google connection uses read-only Gmail, Drive, Docs and Sheets access. Calendar access permits the owner's requested event edits. The personal connection does not request permission to send email.

A private application, not a public service

The assistant itself runs on owner-controlled computers. This website contains only public app information. It has no sign-in form, account connection, API, analytics, or access to the assistant or Google account data.
